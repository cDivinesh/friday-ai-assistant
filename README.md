# FRIDAY - AI Virtual Assistant

A desktop AI assistant with voice interaction, speech recognition, and system automation, built with a futuristic HUD-style interface.

## What it does
Listens for voice commands and responds with speech. Can perform tasks like opening applications, searching the web, and giving system information.

## Tech Stack
- Python
- PyQt (HUD interface)
- SpeechRecognition
- pyttsx3 (text-to-speech)

## How to Run
git clone https://github.com/cDivinesh/friday-ai-assistant
cd friday-ai-assistant
python main.py

## What I Learned
Learned how to integrate speech recognition, build a responsive PyQt interface, and handle real-time voice input and output.
